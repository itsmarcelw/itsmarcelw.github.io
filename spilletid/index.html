    Google Apps Script Sky-Synkronisering

    Integrér med dit eget Google Sheet via en Apps Script Web App for automatisk realtidsdeling mellem alle trænere.

    Sky-synkronisering er ikke aktiveret endnu.

    Trin-for-trin opsætning i Google Sheets:

    1. Opret et nyt Google Sheet på din Google Drive.
    2. Klik på Udvidelser > Apps Script i menuen.
    3. Slet alt kode og indsæt koden nedenfor:
    // Google Apps Script Backend for Volleyball Spilletid function doGet(e) { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); var data = sheet.getRange("A1").getValue(); return ContentService.createTextOutput(data || "{}") .setMimeType(ContentService.MimeType.JSON); } function doPost(e) { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); var contents = e.postData.contents; sheet.getRange("A1").setValue(contents); sheet.getRange("B1").setValue("Senest opdateret: " + new Date().toLocaleString("da-DK")); return ContentService.createTextOutput(JSON.stringify({ status: "success", timestamp: new Date() })) .setMimeType(ContentService.MimeType.JSON); }
    1. Klik på Udrul > Ny udrulning.
    2. Vælg type: Webapplikation.
    3. Sæt Kør som: Mig og Hvem har adgang: Alle.
    4. Kopiér Web-appens URL og indsæt den i feltet ovenfor!

      Regler appen tager højde for

      Baseret på FIVB's officielle volleyballregler 2025–2028.

      Opstilling og positioner. I 5-1 står hæveren diagonalt over for diagonalspilleren, de to kantspillere over for hinanden og de to centre over for hinanden på banen (Pos 1-6).
      Udskiftninger. Op til 6 udskiftninger pr. sæt. Startspillere må kun gå ud og ind igen én gang pr. sæt med den samme indskiftede spiller.
      Libero. Op til 2 liberoer. Liberoen tæller ikke som udskiftning og kan kun spille i bagerste række.
      5-Sæt Printskabelon. Opstillingsseddelen er tilpasset A4 Stående (3 baner øverst, 2 nederst) med store boks-størrelser til kuglepen.
